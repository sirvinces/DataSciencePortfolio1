# Interactive Greeting Project 

## About This Project 
This is my first project stored in my Data Science GitHub portfolio. 

## What It Does 
This Python program asks the user for their name and displays a personalized greeting. 

## Tools Used 
- Python
- GitHub
- Markdown

## What I Learned
I learned how to track changes and manage version control using meaningful commits in GitHub. On the Python side, I learned how to clean string inputs using .strip() and .title(), and how to use if/elif/else conditional logic to make a program respond dynamically to different user choices.

## Future Improvements
If I continued working on this project, I would expand it to read user data from a CSV file using Python's pandas library, allowing the script to automate personalized greetings for an entire roster of students or a list of hackathon participants all at once. I might also try exporting the stored answers to visualize the programming language preferences in Power BI.
